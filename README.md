# 教师实训报告批量处理系统

本地运行的教师实训报告批量处理辅助系统，用于高效完成学生实训 Word 报告的规范化管理、成绩录入、评语自动生成与结果汇总。

## 功能特性

- **Word 文档解析**：批量读取实训报告，自动提取学号、姓名、课程名称、实训名称
- **文件规范化重命名**：按统一格式重命名文件（学号_姓名_课程名称_实训名称.docx）
- **成绩录入管理**：教师手动输入成绩，系统不参与自动评分
- **评语自动生成**：基于分数区间生成差异化评语，支持重新生成和手动编辑
- **评语写回 Word**：将评语按规范格式写入文档
- **Excel 成绩汇总**：一键导出成绩汇总表

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 使用流程

1. 启动程序，选择包含学生实训 Word 的文件夹
2. 系统自动解析文档并生成学生列表
3. 教师逐一输入或调整学生分数
4. 点击"生成评语"按钮批量生成评语
5. 可抽查、修改或重新生成个别评语（双击评语列编辑）
6. 点击"写入 Word 文档"将评语写入文件
7. 点击"导出成绩汇总 Excel"完成本次实训批改

## 技术栈

- Python 3.9+
- PySide6（GUI 框架）
- python-docx（Word 文档处理）
- openpyxl（Excel 导出）

## 评语生成规则

| 分数区间 | 评价等级 |
|---------|---------|
| ≥ 90    | 优秀    |
| 80–89   | 良好    |
| 70–79   | 中等    |
| < 70    | 待提高  |

每个等级维护三个语义池（总体评价、具体表现、改进建议），生成时随机组合，保证同分段评语不完全重复。
